1. INTRODUCTION                                           *jason-introduction*

jason.nvim adds filetype detection, syntax highlighting, indentation,
snippets, linting, formatting and Jason CLI integration for Jason agent programs (`*.asl`) and
multi-agent system project files (`*.mas2j`).

No setup() call is needed.

==============================================================================
2. FILETYPES                                                 *jason-filetypes*

`*.asl`     filetype `jason`
`*.mas2j`   filetype `mas2j`

Both set 'commentstring' to `// %s`. Unless |g:jason_recommended_style| is
false, they also set 'expandtab' with 'shiftwidth', 'softtabstop' and
'tabstop' at 4.

                                                  *g:jason_recommended_style*
Set to |v:false| to keep your own indentation options: >lua
    vim.g.jason_recommended_style = false
<
==============================================================================
3. COMMANDS                                                   *jason-commands*

                                                                      *:Jason*
:Jason run [file]       Run [file] (a `.mas2j`) or the project file nearest
                        to the current buffer.
:Jason compile          Run `jason app compile` in the project root.
:Jason stop             Stop the system started by the terminal runner.
:Jason mind             Open the Mind Inspector (|jason-config-mind_url|).
:Jason format           Format the current buffer (|jason-formatting|).
:Jason new {name}       Run `jason app create {name}` in the current
                        directory.
:Jason add-agent {name} Run `jason app add-agent {name}` in the project root.

The project file is the buffer itself when it is a `.mas2j`; otherwise it is
the nearest `.mas2j` found searching upward from the buffer, then from the
current directory. When a directory holds several you're asked to choose.

`new` and `add-agent` ask for {name} with |vim.ui.input()| when it is
omitted.

==============================================================================
4. MAPPINGS                                                   *jason-mappings*

No keys are mapped. The following <Plug> mappings are available:

<Plug>(jason-run)       |:Jason| run
<Plug>(jason-compile)   |:Jason| compile
<Plug>(jason-stop)      |:Jason| stop
<Plug>(jason-mind)      |:Jason| mind

==============================================================================
5. TREE-SITTER                                              *jason-treesitter*

The `jason` parser (tree-sitter-jason) is registered with nvim-treesitter
(`main` branch), so `:TSInstall jason` installs it together with its queries
(highlights, folds, textobjects, locals). When the parser is installed, jason
buffers start tree-sitter highlighting and the Vim syntax is turned off;
indentation keeps using the plugin's rules. See |jason-config-treesitter|.

==============================================================================
6. LANGUAGE SERVER                                                 *jason-lsp*

`lsp/jason_ls.lua` configures jason-language-server for |vim.lsp.config()|.
With `jason-language-server` on your PATH: >lua
    vim.lsp.enable("jason_ls")
<
The root is the directory holding the `.mas2j` file, else the git root.
Override the command for a local build: >lua
    vim.lsp.config("jason_ls", {
      cmd = { "node", "/path/to/jason-language-server/dist/server.js", "--stdio" },
    })
<
==============================================================================
7. LINTING                                                     *jason-linting*

The `jasonlint` linter for nvim-lint runs the parsers bundled in the Jason
jar on the buffer contents: >lua
    require("lint").linters_by_ft.jason = { "jasonlint" }
    require("lint").linters_by_ft.mas2j = { "jasonlint" }
<
The jar is found through the `jason` launcher (|jason-config-cmd|) or set
with |jason-config-jar|. On first use `tools/JasonLint.java` is compiled into
`stdpath("cache")/jason.nvim/` in the background (needs `javac`); until then
Java runs the source file directly, which is slower.

The parser stops at the first error, so there is one diagnostic at a time.
Directives registered by a project's `.mas2j` cannot be checked in a single
file: they are reported as a warning and the rest of the file is skipped.

==============================================================================
8. FORMATTING                                               *jason-formatting*

The `jasonfmt` formatter for conform.nvim, also available as `:Jason format`: >lua
    require("conform").formatters_by_ft.jason = { "jasonfmt" }
    require("conform").formatters_by_ft.mas2j = { "jasonfmt" }
<
It only changes whitespace outside strings, quoted atoms and comments: one
space around `<-`, `:-`, `<:`, `&` and the context `:`; no space before `,` and
`;` and one after; trailing whitespace removed; blank-line runs collapsed;
lines re-indented with the plugin's indent rules. Long lines are not broken.

==============================================================================
9. CONFIGURATION                                         *jason-configuration*

Pass options to `require("jason").setup()` or set `vim.g.jason` before the
plugin loads. Defaults: >lua
    {
      cmd = "jason",
      jar = nil,
      run_args = {},
      mind_url = "http://127.0.0.1:3272",
      runner = "terminal",
      terminal = { position = "botright", size = 15 },
      treesitter = {
        highlight = true,
        url = "https://github.com/RayIci/tree-sitter-jason",
        revision = nil,
        path = nil,
      },
    }
<
cmd                                                     *jason-config-cmd*
    Jason CLI executable.

jar                                                     *jason-config-jar*
    Jason jar used by the linter. Default: the file the `cmd` launcher
    resolves to (the launcher is a jar with a shell stub).

run_args                                           *jason-config-run_args*
    Extra arguments appended to `jason <app>.mas2j`.

mind_url                                           *jason-config-mind_url*
    URL opened by `:Jason mind`.

runner                                               *jason-config-runner*
    `"terminal"` runs commands in a split terminal. A function receives
    `{ name, cmd, cwd }` and runs it however you like (overseer, toggleterm,
    and so on). `:Jason stop` only knows about the terminal runner.

terminal                                           *jason-config-terminal*
    Split used by the terminal runner: `position` is a |:vertical| or
    |:botright| style modifier, `size` the height (or width).

treesitter                                       *jason-config-treesitter*
    `highlight`: start tree-sitter highlighting when the parser is
    installed. `url` and `revision`: where `:TSInstall jason` gets the
    grammar. `path`: a local tree-sitter-jason checkout used instead of
    `url`. These options are read when nvim-treesitter installs or updates
    parsers, so set them before that (e.g. with `vim.g.jason`).

10. HIGHLIGHT GROUPS                                        *jason-highlights*

These are the Vim syntax groups, used without the tree-sitter parser.
Groups are linked by default and can be overridden with |nvim_set_hl()|.

jason:  jasonTrigger, jasonGoal, jasonBeliefUpdate, jasonInternalAction,
        jasonFunctor, jasonNamespace, jasonVariable, jasonAnonVar,
        jasonLabel, jasonAnnotation, jasonPerformative, jasonDirective,
        jasonArrow, jasonNegation, jasonOperator, jasonConditional,
        jasonRepeat, jasonBoolean, jasonNumber, jasonString,
        jasonQuotedAtom, jasonEnd, jasonComment, jasonTodo

mas2j:  mas2jKeyword, mas2jSection, mas2jOption, mas2jValue, mas2jBoolean,
        mas2jClass, mas2jCount, mas2jNumber, mas2jString, mas2jDelimiter,
        mas2jComment, mas2jTodo
